## Approach

Build a fresh **Next.js App Router** portfolio in the empty repository, replacing the current single-file, gradient-heavy HTML with a restrained editorial-light design. I’ll target a **generalist Software Engineer** audience: strong on real project evidence, equally credible across full-stack development and applied AI.

### Design direction
- **Warm editorial palette:** ivory background, near-black text, and a restrained deep-green accent instead of indigo/purple gradients.
- **Typography-led layout:** large editorial headline, generous whitespace, thin dividers, and compact metadata labels—no glassmorphism, neon effects, or floating icon cards.
- **Clear recruiter path:** Hero → selected projects → education and toolkit → contact, with persistent navigation and visible GitHub/email/LinkedIn actions.
- **Accessible and responsive:** semantic landmarks, visible keyboard focus, reduced-motion support, responsive navigation, and properly labelled external links. A text-based monogram replaces the remote social-media profile photo so the site is self-contained and faster.

### Project structure
- `package.json`, TypeScript and Next.js configuration, and `eslint.config.mjs`
- `src/app/layout.tsx`, `src/app/page.tsx`, `src/app/globals.css`, and a metadata/OG image route
- `src/components/` for header, hero, project cards, experience, skills, contact, and footer
- `src/data/portfolio.ts` to keep all editable content—bio, education, projects, skills, and links—in one place
- `public/` assets plus a concise `README.md` with local setup and deployment instructions

### Content and project decisions
- Use only information present in the source portfolio; don’t fabricate employers, dates, metrics, or achievements.
- Lead with the two real, repository-backed projects: **HemoCare** (Flutter/Firebase/Dart) and **Face Recognition** (Python/TensorFlow/OpenCV). Use a GitHub CTA for additional work instead of presenting an unverifiable third project.
- Present the **Master’s in Artificial Intelligence (2025–2027)** and **BSc Computer Science (2022–2025)** as the education timeline.
- Show skills as a grouped toolkit (Languages, Backend & Data, Mobile, AI/ML, Practices), with no arbitrary percentage bars.
- Keep the provided GitHub, LinkedIn, X, Instagram, email, and location links, but make GitHub, email, and LinkedIn the primary professional calls to action.

### Verification
- Install dependencies with npm and run ESLint and a production build.
- Check the resulting source for the requested visual hierarchy, content accuracy, and all link targets.
- Report any unavailable external image or deployment limitation separately; the page itself will not depend on that image.
